# Level-Aware Maze Game via Monte Carlo

This repository contains a procedural maze generator and a playable Pygame game for a stamina-based escape maze. The generator uses a Metropolis-Hastings style Monte Carlo search to create valid maps whose measured difficulty is close to a target value.

## Game Idea

The player starts at `S` and must reach the door `D`. A door may require a key `K`. Movement consumes stamina, and stamina potions `T` restore stamina. If the door is locked, it behaves like a wall until the key is collected.

The game also supports fog of war: only cells inside the player vision radius are visible while playing.

## Main Features

- Difficulty-aware map generation with MCMC.
- Hard constraints for connectivity, maze shape, solvability, and valid locked-door placement.
- Exact stamina-aware HC3 solver for theoretical solvability.
- Segment-level Monte Carlo agents for practical difficulty estimation.
- Pygame visualization, solution replay, and playable fog-of-war mode.
- Custom map mode and 20-level campaign mode.
- Windows executable build script with PyInstaller.

## Run the Playable Game

Install dependencies first:

```bash
pip install pygame matplotlib
```

Run the full menu game:

```bash
python difficulty_stamina_game.py
```

Other useful entry points:

```bash
python baseline_pipeline.py
python viz_maze.py
python play_maze.py
```

## Build a Windows Executable

The project includes a PowerShell build script:

```powershell
powershell -ExecutionPolicy Bypass -File .\build_game.ps1
```

The executable is written to:

```text
dist/DifficultyStaminaMaze.exe
```

## Report and Analysis

The IEEE-style project report is in:

```text
project_report/main.tex
```

Monte Carlo analysis outputs are generated by:

```bash
python project_report/scripts/run_monte_carlo_analysis.py
```

The script writes CSV files, LaTeX tables, plots, and map examples to:

```text
project_report/analysis_results/
```
